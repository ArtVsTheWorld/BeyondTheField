# Dynasty Enhancer roadmap

## Next: native Dynasty lifecycle

- Read the active Dynasty and user program from runtime state instead of a configured save file.
- Publish an edition after week advancement finishes updating results, statistics, polls, recruiting, and injuries.
- Add midweek events to that same publication week without requiring a save.
- Keep events stable and deduplicated, isolate leagues/seasons, and handle loading an older save or replaying a week with different outcomes.
- Preserve native menu behavior, controller navigation, and read-only simulation access.

## Then: richer Social Media

Expand conditional prewritten voices and stories for depth-chart status, injuries, age, transfer risk, NIL, rivalries, awards, and the national postseason picture. Preserve a curated combined feed and complete category feeds.

## Planned 1.0 integration

1. Native Social Media with active-Dynasty and week/midweek lifecycle support.
2. Existing player analytics grades mod, integrated as a component.
3. Existing ratings fog-of-war mod, replacing numerical player-rating displays throughout the UI with less granular information.

The analytics and fog-of-war components are planned integrations, not included in this baseline. Version 1.0 follows integration and validation of all three. The product goal is more convincing Dynasty context and presentation without structural changes to Dynasty data or altered simulation outcomes.
