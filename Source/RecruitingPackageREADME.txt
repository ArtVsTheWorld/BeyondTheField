Dynasty Enhancer - Combined Prototype

One Dynasty Enhancer MMC plugin automatically loads Social Media and native
recruiting letter grades/ranges, Playing Time masking and the Notes tab.
Notes include a generated previous high-school season, independent academic
GPA, and football scouting observations. GPA is background only and does not
indicate stars, ratings or development. Football observations unlock as scouting
reveals their underlying public grade bounds. The generated 1A-6A scale is a consistent competition
model. Game JUCO recruits receive fictional D3/D2/FCS school backgrounds;
portal transfers use recorded college statistics. Grades use native font colors.
Underlying player ratings, recruiting results and game saves are not changed.

Install the full Plugins folder into MMC with CFB and MMC closed. Enable
Dynasty Enhancer (Prototype) and launch CFB through MMC. Both native components
load automatically; no manual DLL injection or title-screen wait is required.

Generated resumes are stored beside the native components under
RecruitResumeHistory. Preserve that folder when moving the installation.
Existing configuration and Social Media history are preserved on update.
This remains a development prototype rather than the planned 1.0 release.
